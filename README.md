# TOEIC AI Trainer

AI生成問題で4技能（Listening / Reading / Speaking / Writing）を鍛えるTOEIC学習PWAアプリです。

## 🚀 セットアップ

### 1. アプリにアクセス

スマホのChromeで以下のURLを開いてください：

```
https://myaotti1979-hub.github.io/TOEIC-Trainer/
```

### 2. ホーム画面に追加

Chrome メニュー →「ホーム画面に追加」→ PWAとしてインストールされます。

### 3. APIキー設定

| キー | 取得先 | 用途 | 必須 |
|------|--------|------|------|
| Gemini API | [Google AI Studio](https://aistudio.google.com/apikey) | 難易度判定・英作文添削 | 判定時のみ |
| Azure Speech | [Azure Portal](https://portal.azure.com) → Speech Service | ロールプレイ発音チェック | ロールプレイのみ |

- **APIキーなしでも**ストック学習・単語帳・模試は利用できます。
- Gemini API: 無料枠で十分。APIキー設定画面で入力。
- Azure Speech: S0（従量課金）推奨。HOME画面の「🎭 Azure設定」から入力。

### 4. 問題データのインポート

1. このリポジトリの [Releases](../../releases) ページを開く
2. 最新リリースからJSONファイルをダウンロード
3. HOME画面 →「📥 インポート」
4. ダウンロードしたJSONを選択（複数ファイル同時選択可）
5. 模試JSONは「🎯 模試」画面から専用インポート（複数ファイル対応）

> **ファイルサイズ**: パートによって100MB前後に分割されています。3-5ファイルずつインポートしてください。

### 5. 難易度判定（推奨）

インポート後、問題管理画面の「🎯 未判定を判定」で難易度を付与すると、実力レベルに合った出題やスコア推定が正確になります。

> Gemini APIキーが必要です。

## 📱 使い方

### HOME画面

| ボタン | 説明 |
|--------|------|
| ▶ 通常 | 全問題からタイプ分散シャッフル（品質A/B優先） |
| 🆕 未回答 | 初見の問題だけ出題 |
| 🔥 苦手特訓 | 正答率70%未満のタイプのみ |
| 🎯 最適レベル | 推定スコア±150点の問題 |

### 回答前：自信度（任意）

💪自信あり / 🤔たぶん / 🎲カン をタップしてから回答すると、自信度分析に反映されます。

### 回答後の追加機能

| 機能 | 対象 | 説明 |
|------|------|------|
| 🎭 ロールプレイ | Part 3/4 | Azure発音評価付き会話練習。単語タップで単語帳連携 |
| 🎙️ シャドーイング | Part 3/4 | 1文ずつ再生→真似る→確認 |
| ✍️ 英作文 | Part 5 | 同じ文法で英作文→Gemini 3軸添削 |
| 📖 WPM | Part 7 | 読速の自動計測（目標150 WPM） |

### 実力診断

HOME →「📊 実力診断」で確認できます：

- IRT推定TOEICスコア（L/R内訳、本番の問題数比率で加重）
- パート別弱点タイプ
- 自信度分析（2×3マトリクス）
- 間違いパターン分析
- スピーキング診断（5軸レーダーチャート）
- ライティング診断（Grammar/Vocabulary/Relevance）

### 💾 バックアップ

HOME →「💾 バックアップ」で学習データを保存できます（2-5MB）。

- 判定履歴・単語帳・模試結果・問題メタデータ・設定を保存
- 週1回のリマインダー付き、データ消失時は自動検知
- 問題データ本体はReleasesから再インポート → バックアップ再復元で完全復旧
